TallyBook

A fast, local-first finance ledger for Linux

Python / PySide6 SQLite3 AppImage Linux

TallyBook is a desktop financial ledger application built with Python and PySide6. It provides a comprehensive double-entry bookkeeping system for tracking personal or small business finances, wrapped in a dark-themed interface with orange accents.

⤑ Quick Start

Download

Get the latest TallyBook-x86_64.AppImage from the GitHub Releases page. Save it in a dedicated folder like ~/Applications.

Make Executable

Open a terminal in the folder where you saved the AppImage and run:

chmod +x TallyBook-x86_64.AppImage

Launch

Double-click the file to launch. On first run, it will automatically create your database and optionally integrate with your desktop environment (application menu & dock).

Updates

Download the newest AppImage version and replace your old one. Your ledger data is stored separately and will be found automatically.

⤑ Building

AppImage (Docker)

Build a portable Linux AppImage with maximum GLIBC compatibility.

./scripts/build_with_docker.sh

PyInstaller (Local)

Build a standalone binary directly on your system.

pyinstaller TallyBook.spec
